# Task Manager CLI

A simple command-line task manager built with core Python basics (lists, dictionaries, loops, conditionals, and string methods).

This is an early-stage learning project. New versions will be released as I improve my Python skills, gradually adding more advanced concepts such as functions, file handling, and error handling.

## Features

- Add new tasks
- List all tasks
- Mark tasks as complete
- Remove tasks

## How to Run

Make sure you have Python installed, then run:

```bash
python main.py
```
